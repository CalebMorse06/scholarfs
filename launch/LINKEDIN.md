# LinkedIn draft

Today I am sharing ScholarFS, an open-source, local-first workspace standard for AI-native students.

The idea came from a practical problem: course context is fragmented across learning-management systems, syllabus PDFs, calendars, folders, notes, and temporary AI conversations. Students repeatedly reconstruct that context, while the useful parts can become trapped inside one vendor's memory system.

ScholarFS gives that information a consistent, student-owned home:

- courses, deadlines, and notes stored in ordinary files;
- explicit, editable memory instead of opaque model memory;
- a provider-neutral structure that works with different assistants;
- published schemas and a small Python CLI for creation and validation;
- calendar export and a safe file boundary for future LMS connectors.

v0.1 deliberately focuses on the foundation rather than a frontend or hosted service. Core has no account, telemetry, network access, or credential handling. The repository includes the standard, CLI, documentation, privacy guidance, and a completely fictional semester.

If you are a student, educator, or developer working on personal knowledge systems, I would value your feedback, especially on onboarding and the deadline model.
